# LabGit-Settings

## Назначение проекта
Учебный проект для выполнения лабораторной работы по дисциплине «Инструментальные средства разработки программного обеспечения». Цель проекта — изучение настроек фильтрации, атрибутов и структуры репозитория.

## Структура каталогов
* `src/` — исходный код приложения (содержит `Program.cs`)
* `docs/` — документация к проекту
* `tests/` — тестовые материалы
* `assets/` — вспомогательные файлы и ресурсы

## Исключаемые типы файлов (.gitignore)
В репозитории настроено игнорирование служебных папок компиляции (`bin/`, `obj/`, `build/`), временных файлов (`*.tmp`, `*.bak`), логов (`*.log`), локальных настроек (`.env`) и конфигураций IDE (`.vs/`, `.vscode/`).

## Использованные настройки репозитория (.gitattributes)
* Включено автоматическое определение текстовых файлов (`text=auto`).
* Для файлов кода C# (`.cs`) заданы окончания строк `CRLF`.
* Для файлов документации (`.md`, `.txt`) заданы окончания строк `LF`.
* Изображения, PDF и архивы зафиксированы как бинарные данные.
